# 문제 분석

## 입력

- 맵을 나타내는 이차원 배열 (0이 벽, 1이 통로)

## 출력

- 우리팀 캐릭터가 상대 팀 진영에 도착하기 위해 지나가야 하는 길의 최소 갯수를 정수로 반환

## 풀이

- 너비 우선 탐색이 최단 경로를 보장하기 때문에, 너비우선탐색으로 한 칸씩 이동해보면서 막힌 공간일 경우 되돌아가고 하면서 찾아보자

### 42-a의 문제점

- 예를 들어서 [3,3]에 있을 때는, [3,2]와 [4,3] 둘 다 적합한 경로 이므로 둘 다 visited와 queue에 추가되어버림
  - 둘을 구분할 수는 없나?

* GPT 말로는 둘을 구분할 필요없다고함
  - 애초에 둘 다 큐에 추가되는게 올바른 너비우선탐색임
  - 대신 로직에 dist라는 이차원 배열을 추가하여, 해당 위치까지 가는데 걸린 경로를 계속 기록하면서 추적해주면됨
  * dist에는 적합한 경로까지 걸린 길이가 계속해서 추가됨 -> 그런데 다만 원하는 목적지 경로까지 도착하면 그 경로가 최소 경로임을 의미하는것이므로 해당 경로의 dist 값을 구하면 그것이 최소 경로길이가됨
