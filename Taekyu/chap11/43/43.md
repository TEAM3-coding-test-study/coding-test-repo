# 분석

## 입력

- computers : 이차원 배열로 노드간 연결관계 표현
  - ex. computers[0,1] == 1 이면 연결된것

* n : 컴퓨터의 갯수

## 출력

- 네트워크 갯수 (연결된 묶음이 하나의 네트워크)

## 풀이

- 지난번에 풀었던 섬 연결 문제와 같은 로직인듯...

* 처음 노드부터 시작해서 깊이 우선 탐색으로 진행하고, 끝까지 진행했을 때 <- 이게 하나의 네트워크
* 그 후 visited에 들어있지 않은 노드부터 다시 시작해서 모든 노드를 위의 방식으로 탐색(물론 이 순회때마다 count를 up)
* 이렇게해서 정해진 count를 네트워크의 갯수로 확정

* 근데 생각해보니까 사이클에 대한 고려를 안함

  - 더이상 자식 노드가 없을 때 뿐만아니라, 사이클이 완성된 경우에도 하나의 네트워크로서 성립

* GG

## 교재
