# 문제 분석

## 풀이

- 그냥 책에 있는 방식을 그대로 코드로 옮긴 것이기에 크게 할 말은 없다

- stack : 최근 방문한 노드를 기억하기 위한 스택
- visited : 탐색 순서대로 노드가 저장된 리스트

- 초기 노드를 스택에 푸쉬
- 그러고 while문을 돌면서 탐색을 진행
  - 스택의 크기가 0이 되면 더 이상 탐색할 노드가 없다는 뜻이므로 반복문 탈출
  - 스택에서 pop을 하고, pop한 노드가 방문한 노드인지 확인 -> 아직 방문안한 노드인 경우 방문 처리
  - 이후 그래프를 순회하면서 방문한 노드와 인접하면서 아직 방문은 안한 노드를 찾고 스택에 푸쉬
    - 그러고 나서 다시 처음부터 반복
    - 이때 그래프에 reverse를 걸어주는 이유는 스택에 역순으로 푸쉬해야 방문처리(pop)는 정방향 순서대로 할 수 있기 때문

* 답과 다름 -> reverse 메서드가 원본 배열의 순서를 변경시키기 때문에 자꾸 배열이 역순으로 계속 바뀌는 문제 떄문
  - 그래서 그냥 for문으로 인덱스를 역순으로 순회하도록 변경
