# 문제 분석

## 입력

- 게임 참가자수 : N
- 참가자 번호 A
- 참가자 번호 B

## 출력

- 토너먼트인데, 번호를 순차적으로 배정받고 상위 토너먼트에서도 다시 순차적으로 배정 받음
- 근데 A가 그러면 몇 라운드에서 B를 만나는지를 출력하는거임 (A와 B는 만나기전까지 항상 이긴다고 가정)

## 풀이

- 토너먼트 자체가 트리 형태기는 함

```
          1
        1 / 2
      1 2 / 3 4
1 2 / 3 4 / 5 6 / 7 8
```

위와같은 형태가 되도록 트리를 구성하면 좋을것같음

- 그럼 이제 문제는 몇 라운드에서 만나는지를 구하는 로직
  - 위의 예제의 경우, 1 <-> 2 : 1라운드
  - 1 <-> 3 : 2라운드
  * 1 <-> 5 : 3라운드
  * 1 <-> 7 : 3라운드

* N을 2로 나눈 범위 : [1,2], [3,4], [5,6], [7,8] 에서 1과 7이 떨어져있는 거리는 3 = a
* A와 B가 포함되어 있는 집합의 크기를 구함 -> 8 = 2 ^ 3 -> 3라운드
* 1과 2의 경우 -> 2 = 2 ^ 1 -> 1라운드

  - 만약 반대쪽에 속한다면 걍 2^a = N일때의 a이다
