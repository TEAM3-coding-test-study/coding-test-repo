# 문제 분석

## 입력

- 판매원의 이름 담긴 배열 : enroll
- 각 판매원을 다단계 조직에 참여시킨 다른 팜애원의 이름을 담은 배열 referral
- 판매량 집계 데이터의 판매원 이름을 나열한 배열 seller
- 판매량 집계 데이터의 판매 수량을 나열한 배열 amount

## 출력

- 각 판매원이 얻은 이익금을 나열한 배열 반환

## 풀이

- 일단 책에 나온대로 트리 자료구조를 만들어야되는데, 지금까지와 같은 이진 트리도 아니고... 어떻게 만들어야할지 난감함

* 연결리스트로 만들고, 판매원이 얻은 이익금이 위로 전파되는 구조를 만들어야할듯
  - 근데 부모가 여러 자식을 가질 수 있기때문에 선형 자료구조인 연결리스트는 적합하지 않은것같다
* 포기

## 교재

- 트리를 안씀
  - 근데 트리 챕터인데 왜 트리를 안쓰는거지...

* 오브젝트를 써서 계층관계를 표현... 신박하네
