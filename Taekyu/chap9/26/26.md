# 문제 분석

## 풀이

- 전위 순회
  - 현재 인덱스를 기억하면서, 현재 인덱스에 데이터가 있으면 returnArr에 push하고 왼쪽 자식으로 내려감
  - 쭉 내려가다가 데이터 없는 인덱스면 부모로 다시 올라감
  - 부모에서 이제 우측자식으로 내려가야함 <- 이걸 어떻게 구현할까?
    - 우선 부모가 이미 순회했던 데이터인지를 파악해야함 -> 이거는 includes 메서드를 이용해 이미 방문한 노드인지 확인함으로써 가능
  * if 문으로 우선순위를 둬서, 매 순회마다 먼저 자신(부모)를 확인하고, 그 다음 왼쪽 자식, 그 다음 오른쪽 자식, 다 없으면 다시 부모로 이동 하는 형식으로 진행한다

* 중위 순회

  - 우선 좌 자식으로 쭈욱 내려가고, 왼쪽 자식이 없으면 부모, 그리고 나서 오른쪽 자식으로 가는 순회를 해야함

  * 따라서 if 문 순서를 바꿔서 왼쪽 자식 체크, 자신 체크, 오른쪽 자식 체크 하도록 진행함

* 후위 순회
  - 순서를 바꿔서 왼쪽 자식, 오른쪽 자식, 그 다음 자신을 확인하도록함
