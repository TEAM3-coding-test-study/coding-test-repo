# 문제 분석

## 입력

- 각 노드의 양 또는 늑대 정보가 담긴 배열 info
- 이진 트리의 각 노드들의 연결 관계가 담긴 2차원 배열 edges
  - ex [[부모노드번호, 자식노드번호], [부,자], ...]

## 출력

- 모은 늑대수가 양 수보다 같거나 많으면 그 즉시 모든 양이 잡아먹힘

* 양이 안잡아먹히도록 하면서 모을 수 있는 양의 최대 수를 반환

## 생각

- 이것도 내가 볼때는 저번 문제들처럼 트리를 직접 만들어서 하는것으로는 답이 없을것같다
- 지난번 문제처럼, 객체로 부모 : 자식으로 묶어서, 끝까지 순회한 뒤에 다시 루트로 돌아오고하는 계속해서 순화하는 방식은 어떨까?
  - 근데 그러면 루트로 돌아왔을때, 어떻게 기존에 갔던 경로와 구분해서 새로운 경로를 탐색하지?
  * 루트가 아니라 분기점이 있는 조상노드로 돌아오도록해야될것같은데
  * 방문했던 노드는 집합에 넣어놓고, 부모로 올라간다음 자식들을 체크하면서 방문하지 않았던 노드가 있는지 살펴보는식으로하면 어떨까

* 자료구조 변경
  부모 -> 자식
  {
  0: [1,2],
  1: [3,4],
  ...
  }
  자식 -> 부모
  {
  1: 0,
  2: 0,
  3: 1,
  ...
  }

  - 근데 이렇게하면, 분기점에서 먼저 어떤 경로를 택하는지, 그 순서에따라서 또 최대로 모을 수 있는 양이 달라지는거 아닌가?
