# 문제 분석

## 입력

- 미로를 나타내는 문자열 배열 maps

## 출력

- 미로를 탈출하는데 필요한 최소 시간 (탈출 불가능이면 -1)

## 풀이

- 아예 어떻게 풀지 발상을 못하겠음...
- 최단 경로를 어떻게 구하지..?

# 교재

- 너비 우선 탐색
  - 현재 지점에서 갈 수 있는 모든 경로롤 뻗어나가는 방식
- 깊이 우선 탐색
  - 경로 중 한 방향의 경로만 선택해서 끝까지 뻗어나가는 방식

* 이 문제에서는 너비 우선 탐색을 사용해야함

  - 각 지점의 단계별 탐색 길이가 같으므로 도착 지점까지의 최단거리를 찾을 수 있음
  - 각 과정마다 최선의 탐색을 하기 때문에 이미 거쳐온 경로는 다시 탐색하지 않아도됨

* 너비우선탐색은 큐를 사용함
