# 문제 분석

## 풀이

- 주어지는 것은 목적지까지의 거리 N
- 목적지까지 이동하는 방식이 두 종류임
  - 순간이동은 현재까지 온 거리의 2배를 이동하고, 소모값이 없음
  - 점프는 K칸 앞으로 가지만 K만큼의 소모값이 듦
- 이러한 상황에서 소모값을 최소로하면서 목적지에 도착할때의 소모값을 반환해야됨

* 흠... 모든 경우의 수를 다 고려해서 가장 소모값이 작은 때를 찾아내야하나?
  - 근데 모든 경우의 수를 어떻게 다 찾지? 정확히 N에 당도할 수 있는 가짓수를 전부 찾아내야하는데, 어떻게 해야할까?

## 정답

- 규칙을 찾아라
  - 순간이동으로 이동한 위치의 수는 무조건 짝수 -> 위치값으로 순간이동을 했는지 점프를 했는지 알 수 있음
  * 아마 내가 생각하기는 점프를 여러번 해서 짝수가되는건 배제하는 듯 <- 왜냐면 이러면 같은 결과에 대해 소모값이 발생하는 케이스라 문제의 요구사항과 맞지 않기 때문

* 전략 : 종료 위치에서 거꾸로 이동해 처음으로 오면서 점프를 최대한 적게 하는 것

  1. N이 짝수면 순간이동을 했다는 것이므로 N/2로 이동 (배터리 소비 x)
  2. N이 홀수면 점프를 했다는 것이므로 -1로 이동 (배터리 소비 1, 최소로 점프해야하니 -1)

* N을 2로 계속 나누면서, 나머지가 1인 경우만 세면 됨
  - 나머지가 1이면 홀수였다는 의미이므로 점프를 한것이기 때문
