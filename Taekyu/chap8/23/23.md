# 문제 분석

## 입력

- 노래의 장르를 나타내는 문자열 배열 genres
- 노래별 재생 횟수를 나타내는 정수 배열 plays

## 출력

- 베스트 앨범에 들어갈 노래의 고유 번호를 순서대로 배열에 담아 반환
- 베스트 앨범에 노래를 수록하는 순서 기준은 다음과 같음
  1.  장르 -> 소속 노래의 재생수 많은 순 (2개까지)
  2.  장르 내 -> 개별 노래의 재생수 많은 순
  - if 장르내에서 재생횟수 겹치면 고유번호 낮은 순 (장르별 재생수는 무조건 다름)

## 생각

- 객체로 우선 데이터 타입을 정의하면 어떨까
  - 장르별로 구분하여 가장 큰 범위의 키로 객체를 선언 -> 추후 장르별 재생수 구할때 유리
    {
    classic: { '0': 500, '2': 150, '3': 800 },
    pop: { '1': 600, '4': 2500 }
    }
- 이렇게하고, 위의 조건을 맞추기위해 2단계로 나눠서 순서를 정렬
  - 1단계로 객체를 순회하며 각 장르별로 장르내에서 plays를 기준으로 내림차순 정렬
  - 2단계로 각 장르별로 plays값을 더해서 장르별 내림차순 정렬

* GG
  - 자료구조가 객체이므로 정렬하는데 너무 로직이 복잡해짐..

## 교재 정답

- 내가 처음에 생각했던 배열을 이용한 방식을 사용함
  - 배열을 사용하면 시간복잡도 측면에서 오버될거라고 생각해서 사용하지 않았는데, 시도를 해봐야했나봄..

* 또한 배열로 두 개의 속성을 묶은다음 (ex. [고유번호, 재생수]) sort 메서드로 인덱스를 지정하여 여러 기준을 적용한 정렬을 완성함
  ```
  sortedSongs = genresObj[genre].sort((a, b) => {
    return a[1] === b[1] ? a[0] - b[0] : b[1] - a[1];
  });
  ```
