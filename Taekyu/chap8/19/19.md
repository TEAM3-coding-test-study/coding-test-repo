## 호너의 법칙

- 원래의 해싱 공식

```
s[0] + s[1] * p + s[2] * p^2 + s[3] * p^3 + ... + s[n-1] * p^(n-1)
```

=> 이 방식은 각 문자의 아스키 값에 `p`의 지수를 곱해서 누적하는 방식이다. 그러나 `p^i`를 매번 계산하면 성능이 저하된다.

- 호너의 법칙(Horner’s Rule)을 적용한 형태

```
(...((s[n-1] * p + s[n-2]) * p + s[n-3]) * p + ... + s[0])
```

=> 이런 식으로 중첩된 곱셈으로 표현하면 `p`의 거듭제곱을 직접 계산하지 않고도 결과가 동일해진다.

실제로는 다음과 같이 **앞에서부터 누적하면서 계산**할 수 있다:

```js
let hash = 0;
for (let i = 0; i < str.length; i++) {
  hash = (hash * p + str.charCodeAt(i)) % m;
}
```

=> p의 거듭제곱을 사용하는 것과 수학적으로는 같은 결과이며, 더 효율적
