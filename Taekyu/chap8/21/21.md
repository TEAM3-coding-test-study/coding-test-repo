# 문제 분석

## 입력

- 사용자가 원하는 제품을 나타내는 문자열 배열 want
- 사용자가 원하는 제품의 수향을 나타내는 정수 배열 number
- 마트에서 할인하는 제품을 나타내는 문자열 배열 discount

## 출력

- 회원가입시 사용자가 원하는 제품을 모두 할인받을 수 있는 회원 등록 날짜의 총 일수를 반환 (가능한날이 없으면 0)

## 풀이 생각

- 20번 문제에서 사용했던것처럼, 아이템과 그 갯수를 매핑하여 해시로 저장한 다음, n일차부터 n+10일차 까지 사용자가 원하는 만큼의 아이템 수량이 있는지 체크하는 방식은 어떨까?
  - {1일차 : {chicken : 3, apple : 2, ...}, 2일차 : {}, ... }이런식으로 중첩된 객체를 이용해 해시테이블을 만드는거지
  * 그 후 해시테이블을 순회하면서, 사용자가 원하는 제품들과 그 제품의 수량을 해당 일차가 제공할 수 있는지 판별

```js
{
  '1': { chicken: 1, apple: 3, banana: 2, rice: 2, pork: 2 },
  '2': { chicken: 0, apple: 3, banana: 2, rice: 2, pork: 2, pot: 1 },
  '3': { chicken: 0, apple: 2, banana: 3, rice: 2, pork: 2, pot: 1 },
  '4': { chicken: 0, apple: 2, banana: 3, rice: 2, pork: 2, pot: 1 },
  '5': { chicken: 0, apple: 2, banana: 3, rice: 2, pork: 2, pot: 1 },
  '6': { chicken: 0, apple: 2, banana: 3, rice: 1, pork: 2, pot: 1 },
  '7': { chicken: 0, apple: 1, banana: 3, rice: 1, pork: 2, pot: 1 },
  '8': { chicken: 0, apple: 1, banana: 3, rice: 1, pork: 1, pot: 1 },
  '9': { chicken: 0, apple: 1, banana: 2, rice: 1, pork: 1, pot: 1 },
  '10': { chicken: 0, apple: 1, banana: 2, rice: 1, pork: 0, pot: 1 },
  '11': { chicken: 0, apple: 1, banana: 2, rice: 0, pork: 0, pot: 1 },
  '12': { chicken: 0, apple: 1, banana: 2, rice: 0, pork: 0, pot: 0 },
  '13': { chicken: 0, apple: 1, banana: 1, rice: 0, pork: 0, pot: 0 },
  '14': { chicken: 0, apple: 0, banana: 1, rice: 0, pork: 0, pot: 0 }
}
```

- 성공

## 교재 해답

- 입력값의 관계를 보고 그림을 그리면서 어떤 자료구조를 쓸지 떠올릴수 있어야함!
  - 필자는 number와 want와의 관계를 보고, 이를 객체의 키와 값의 관계로 떠올렸음

* 내가 사려고하는 품목과 품목 갯수를 표현하는 객체 , n일차에 회원가입시 할인받을수 있는 품목과 품목갯수 -> 2가지 객체를 만듦
  - 그리고 두 객체를 비교하기 위해 따로 사용자 정의 함수를 만듦(JS는 따로 두 객체가 동일한지 확인하는 메서드를 제공하지 않기때문)
  * 객체 비교 함수를 이용해 두 객체를 비교해서 같으면 카운팅을 올려주는 방식으로 문제를 해결
