# 문제 분석

## 입력

- participant : 마라톤에 참여한 선수들의 이름 담긴 배열
- completion : 완주한 선수들 이름 담긴 배열

## 출력

- 완주하지 못한 선수의 이름 (딱 한 명)

## 생각

### 20-a

- 동명이인이 있는 경우가 문제
  - 단순히 문자열로만 해시값을 만들면 동명이인을 구별해내지 못한다
  - completion으로 해시테이블을 만들어봤자, 같은 이름의 participant의 경우 둘 다 통과해버리기 때문에, 한 명이 완주하지 못한 사람이더라도 통과해버려서 오류가 난다

### 20-b

- 교재에서는 동명이인 문제를 객체의 value에 동명이인수를 저장하도록 함으로써 해결함
