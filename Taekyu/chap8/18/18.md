# 문제 분석

## 입력

- n개의 양의 정수로 이뤄진 리스트 arr
- 정수 target

## 출력

- 리스트의 두 원소의 합이 target이 되는 경우가 있으면 true, 아니면 false

## 풀이 생각

- 첫 원소부터 시작해서 돌아가면서 전부 순회하는 방식
  - 시간복잡도가 O(N^2)이 되므로 안될듯

* 리스트의 값들을 객체로 저장하고, 이 객체에서...
* 어떤 방식으로 해시를 사용해서 푸는지 모르겠음
* 또 어떤 방식을 쓰면 반복문을 돌리지 않고도 합이 target이 되는 요소들을 찾을수있을지도 모르겠음

* 작은 값부터 시작해서 더해나가고, 만약 누적된 값이 더 커지는 경우 이전에 더했던값을 빼고 다음 인덱스의 요소부터 다시 더해나가면서 체크하면 되지 않을까?
  - "두 수"를 더했을때의 값을 비교하는것이므로 이 방법은 적합하지 x

## 교재 정답

- 해시 테이블을 구비하고, 테이블의 인덱스를 배열의 원소들로 생각하고, 해당 원소가 존재하는 키의 값은 1, 존재하지 않으면 0을 할당
  - 이런식으로 하면 target - 원소인 키에 대해 1인 값이 있으면 합을 통해 target을 만들수있는 두 수가 arr에 있다고 인지
