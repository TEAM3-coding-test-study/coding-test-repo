# 문제 분석

## 입력

- 각 손님들이 주문한 단품 메뉴들이 문자열 형식으로 담긴 배열 orders
- 코스 요리를 구성하는 단품 메뉴들의 갯수가 담긴 배열 course

## 출력

- 주인장이 새로 추가하게될 코스요리의 메뉴 구성을 문자열 형태로 배열에 담아 반환

## 생각

- course에 들어온 코스를 구성하는 단품 갯수를 기준으로세워보자
  - 만약 2라면, orders를 순회하면서 2개를 묶은 요소가 다른 orders 원소에도 2개 이상 있는지 찾아야함
  * 생각해보니까, 2개 있는지만 찾으면됨 -> 왜냐하면 2개든 2개 이상이든 코스로 추가되는것은 같기 때문

* 실험

```js
{
  A: {
    0;
    1;
    2;
  }
  B: {
    1;
    2;
    3;
  }
}
```

- 위와같은 식으로해서 값의 객체의 프로퍼티 수가 k(course의 원소)개 이상인 애들을 조합하면 어떨까
  - 예를들어 스팟이 2개인 경우, AB, AC, AD, ...를 탐색하면서, AB인경우 A의 프로퍼티 키들과 B의 프로퍼티 키들을 비교해서, 겹치는게 2개 이상 있는지 체크

```js
{
  A: [ 0, 1, 3, 5 ],
  B: [ 0, 4 ],
  C: [ 0, 1, 2, 3, 4, 5 ],
  F: [ 0, 4 ],
  G: [ 0, 4 ],
  D: [ 2, 3, 5 ],
  E: [ 2, 3, 5 ],
  H: [ 5 ]
}
```
