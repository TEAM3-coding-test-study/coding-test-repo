# 문제 분석

## 입력

- n : 사람의 수
- words : 사람들이 순서대로 말한 단어가 들은 문자열 배열

## 출력

- [가장 먼저 탈락하는 사람의 번호, 그 사람이 자신의 몇 번째 차례에 탈락했는지]

## 풀이

- 우선 파악해야될 것은 2가지이다
  - 어떤 사람이 말한 단어가 이전에 이미 존재하는지
  - 어떤 사람이 말한 단어가 직전 사람이 말한 단어의 마지막 글자로 시작하는지

* 첫번쨰로, 어떤 사람이 말한 단어가 이미 존재하는 단어인지 확인하려면

  - 일단 그 때까지 언급된 단어들을 전부 Set에 모아놓고, has() 메서드로 확인하면 될것같다

* 두 번째로, 단어가 직전 단어의 마지막 글자로 시작하는지 확인하려면
  - 일단 n명의 사람들이 각자 자신이 순차적으로 언급하게되는 단어들을 갖는 배열들을 만들어준다
    0: [tank, wheel, mother]
    1: [kick, land, robot]
    2: [know, dream, tank]
  * 그런 다음에 반복문을 돌면서, 이를 확인해준다

## 교재

- 굳이 나처럼 직접 이차원 배열을 만들지 않고 모듈러 연산과 몫 연산으로만 해결했음
