# 문제 분석

## 입력

- n : 섬의 갯수
- costs : 섬 사이의 다리를 건설하는 비용
  - [[a,b,c], [d,e,f], ...] 와 같은 이차원 배열로 되어있음
  - costs[i][0]과 costs[i][1]에는 다리 번호, cost[i][2]에는 두 섬을 연결할때 드는 비용

## 출력

- 모든 섬을 통행하는 최소 비용을 리턴하면됨

## 풀이

- 이거 아마 너비우선탐색, 깊이우선탐색쪽 관련 개념인것같은데 아직 안 배워서 개념을 모르겠다...

## 교재

- 문제의 요구사항

  - 모든 섬 연결
  - 연결한 다리 비용이 최소

- 문제 해결을 위한 방식
  - 각 섬 사이의 다리 건설 비용을 오름차순으로 정렬
  - 비용 작은 다리부터 선택해 섬 연결
  - N개의 섬은 N-1개의 다리가 있어야 연결되므로 N-1개의 다리가 선택될때까지 위의 과정 반복
  - 비용 최소화를 위해 다리가 추가될 때 사이클이 형성되지 않도록 해야됨 => 사이클이 만들어지면 불필요한 다리를 놓는것이기 때문에 최소 비용이라는 목적과 맞지가 않음 => 이 때 집합 알고리즘을 사용함

* 사이클 여부 알아내기

  - 연결된 섬은 같은 집합이라고 할 수 있음 -> 다리를 추가할 때 다리에 연결될 섬들의 루트노드를 보고 이것이 같은지 확인하면 사이클을 확인할 수 있음

* 근데 왜 find를 하면서 경로 압축을 하는건지 잘 모르겠다
