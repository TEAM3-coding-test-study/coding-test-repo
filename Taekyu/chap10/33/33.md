# 문제 분석

## 입력

- k : 노드의 갯수
- operations : 수행하는 연산 배열이 들은 이차원 배열

## 출력

- operations의 연산을 모두 수행한 후의 집합의 갯수 -> 집합의 갯수는 배열의 키와 값이 같은 루트 노드의 갯수를 세어서 판별하면 될듯

## 생각

- 한꺼번에 생각하려하면 복잡하니까 각 연산을 따로따로 생각해보자
- find 연산
  - 타깃 노드와 배열을 입력으로 받는다
  - 배열의 인덱스가 자식노드고 값이 부모노드임
    - 반복문을 돌면서 타깃 노드의 인덱스를 시작으로 그 값을 찾는다
    - 만약 그 값이 키(인덱스)와 같으면, 루트 노드를 찾은것으로 간주하고 값을 리턴한다
    - 아니라면 계속해서 반복문을 순회한다

* union 연산
  - find 연산을 이용해서 두 노드의 루트 노드를 각각 찾고, 두 루트 노드의 크기 비교를 통해 새로운 루트가 될 노드와 자식으로 편입될 노드를 찾는다
  - 이후 배열에서 더 작은 노드 번호 인덱스의 값을 더 큰 노드 번호 값으로 재할당해주면된다 (이것이 부모 자식 매핑하는것)

## 교재 풀이

- 나는 find 연산을 반복문을 통해 구현했지만, 교재에서는 재귀 함수를 통해 구현했다
  - 교재에서 find 연산의 결과로 하나의 정수를 반환하라는 제약조건이 있었으니 이 방법이 더 맞는거 아닌가 싶다
