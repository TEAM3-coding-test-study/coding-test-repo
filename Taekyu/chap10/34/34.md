# 문제 분석

## 입력

- nums : N 마리의 포켓몬의 종류 번호가 담긴 배열

## 출력

- N/2 마리의 포켓몬을 선택하는 방법 중 가장 많은 종류를 선택하는 방법의 포켓몬 종류 번호 갯수 리턴

## 풀이

- 일단 최대한 종류가 다양해야하므로, 중복을 제거한 집합을 구해봐야한다
  - 예를 들어 [3, 3, 3, 2, 2, 4] 의 경우 Set() 함수를 적용하면 [3, 2, 4]가 된다
  - if문으로 분기를 걸어서
    - Set의 크기가 N/2보다 크면 결과는 N/2
    - Set의 크기가 N/2보다 작다면 결과는 Set의 크기 (ex. [1,1,1,1,1,1])

## 교재

- 나처럼 if문으로 비교하는 대신, Math.min 빌트인 함수를 통해 크기 비교를 해줬음
- Set 객체
  - 중복 허용 x
  - 순서 x
  * set 자료구조에 특정 요소가 있는지 확인하기 위해서는 has() 메서드를 사용하면 된다

* set()의 시간복잡도는 O(N)
