# 문제 분석

## 입력

- 입력은 단어들로 이루어진 2개의 배열 + 목표 단어 배열 goal

## 출력

- 단어 배열들의 단어를 순차적으로 사용해서 목표 단어 배열을 만들수있는지 여부

## 풀이 생각

- 일단 하나의 단어 배열에서 순차적으로 단어를 써야하기 때문에, 선입선출의 자료구조인 큐를 생각할수있음

* 타겟 단어 배열을 순회하면서, 해당 인덱스의 단어가 두 단어 배열의 front에 있는 경우 그 단어를 pop함
  - 만약 pop이 불가능한 경우, false를 리턴
  - 타겟 단어 배열을 끝까지 순회한 경우 true를 리턴
