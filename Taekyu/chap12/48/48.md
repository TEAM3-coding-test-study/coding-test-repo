# 문제 분석

## 입출력

- 완성된 스도쿠 보드 반환 (스도쿠의 조건에 맞는)

* 해가 유일하지 않을 수 있음

* 스도쿠 규칙
  - 가로줄, 세로줄에는 1부터 9까지의 숫자가 한 번씩 나타나야함
  - 작은 박스에도 1부터 9까지의 숫자가 한 번씩 나타나야함

## 풀이

- 한 칸, 한 칸씩 넣어보면서 조건을 충족했는지 트랙킹해야할 듯
- 유망 함수
  - 행, 열, 해당 셀이 속한 박스를 체크하며 스도쿠의 조건을 동시에 충족하는 숫자가 있는지 체크
  - 셀이 0이 아닌 경우에도 스킵(이미 숫자가 채워져있는 것이므로)

* 위의 방식으로 풀어봤지만 답을 찾을 수 없었음

  - 왜냐하면 그냥 조건에 맞는 수를 찾자마자 바로 대입하다보면, 어느순간에는 1~9까지 중 어느 숫자도 조건에 부합하지 않아서 candidate를 산출해낼 수 없기 때문

  * 예를 들어 0행에서 순차적으로 값을 넣다보면 마지막 열에서는 행 조건을 만족시키려면 무조건 6을 넣어야하는데, 이 6은 이미 박스에 있기 때문에 넣을 수 없음 -> 어떠한 수를 넣어도 조건 만족 불가능

## 교재

- 내가 가진 의문점은 이거임
- 한 칸은 조건을 만족한다고해도, 나중가서 어떤 칸에서는 어떠한 수도 조건을 만족시키지 못하게 될 수도 있는데, 이때 어떻게 해야하나?

* 결론은 역시 재귀였음 -> 즉 안되는 경우가 발생하면 재귀함수를 리턴시켜서, 이전에 되던 곳으로 되돌려야함
* findSolution()에서 빈 칸을 찾고, 일단 값을 넣고 재귀함수를 수행
  - 그러면 다음칸에서도 똑같이 빈 칸을 찾고 값을 할당
  - 만약에 최종적으로 빈 칸이 없으면 true를 리턴
